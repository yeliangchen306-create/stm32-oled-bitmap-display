# 卡通点阵是怎样制作的，以及如何更换图案

[返回 README](../README.md)

## 这张点阵图是怎样做出来的

本项目中的卡通点阵图使用了 **AI 辅助处理**。

我先提供原始卡通图片，让 AI 忽略截图中的日期、按钮和文字，只保留人物，并将人物整理成适合单色 OLED 的黑白线稿。然后再把线稿缩小到 128×64，并转换成 C 语言的十六进制点阵数组。

完整过程是：

```text
原始图片
  ↓
AI 去除文字和无关界面
  ↓
AI 简化成黑白粗线条
  ↓
缩放到 128×64
  ↓
黑白二值化
  ↓
转换为 1024 字节 C 数组
  ↓
写入 OLED_Cartoon.h
```

AI 在这里主要用于清理图片和简化线条。真正发送给 OLED 的仍然是一组普通的 0 和 1 点阵数据。

## 为什么要把图片简化

单色 OLED 只能显示亮点和灭点，没有粉色、灰色和透明度。图片缩小到 128×64 后，过细的头发和阴影也容易消失。

适合 OLED 的图片通常具有这些特点：

- 黑白分明；
- 主体轮廓简单；
- 线条稍粗；
- 细节不要太多；
- 宽高比例接近 2:1。

## 一个字节怎样控制像素

SSD1306 把屏幕分成 8 个 Page，每个 Page 高 8 个像素。数组中的一个字节控制同一列的 8 个像素：

```text
bit0 → 最上面的像素
bit1 → 第二个像素
...
bit7 → 最下面的像素
```

因此程序不是按照普通图片的横向顺序保存，而是把纵向 8 个像素组合成一个字节。

## 更换成自己的图案

### 方法一：使用仓库中的 Python 工具

1. 准备一张黑色线条、白色背景的图片；
2. 安装 Python 3；
3. 安装 Pillow：

```bash
pip install pillow
```

4. 在仓库目录执行：

```bash
python tools/image_to_oled.py my_picture.png bitmap.txt
```

也可以调整黑白阈值：

```bash
python tools/image_to_oled.py my_picture.png bitmap.txt --threshold 190
```

5. 打开生成的 `bitmap.txt`；
6. 复制其中 `CartoonBitmap[1024]` 的内容；
7. 替换 [`OLED_Cartoon.h`](../Hardware/OLED_Cartoon.h) 中原来的同名数组；
8. 重新编译并下载程序。

工具还会生成一张 `_preview.png` 预览图，可以先检查线条是否清楚。

### 方法二：继续使用 AI 辅助

如果原图背景复杂，可以先让 AI：

> 保留图片主体，删除文字和背景，转换成适合 128×64 单色 OLED 的黑白粗线稿，不要灰度和阴影。

得到干净线稿后，再使用上面的 Python 工具转换。

## 显示效果不理想怎么办

| 问题 | 调整方法 |
|---|---|
| 线条断开 | 提高阈值，或先让 AI 加粗线条 |
| 大片区域连在一起 | 降低阈值，减少阴影和细节 |
| 主体太小 | 先裁剪图片，让主体占满画面 |
| 图片变形 | 保持原比例缩放，四周留白 |
| 黑白反了 | 给转换工具加上 `--invert` |

更换图案时不需要修改 `OLED.c` 和 `main.c`，通常只替换 `CartoonBitmap` 数组即可。
